# Ujjawal-K-Panchal.github.io

Personal profile page. Static, no build step, no network at runtime.

- `index.html` — all content
- `assets/site.css` — palette forked from `learning-artefacts/assets/learn.css`; white titles, grey-white subtext
- `assets/site.js` — philosophy loop, identity tabs, earlier-roles fold
- `assets/fonts/` — EB Garamond, bundled

Preview locally:

```bash
python3 -m http.server 8731 --directory .
```
